# Auth page template

Edit **auth_page.html** to change how the Microsoft login success and error pages look in the browser.

## Placeholders (do not remove)

- `{{PAGE_TITLE}}` – Launcher name (e.g. "Matteino Launcher")
- `{{LOGO_IMG}}` – Logo image tag or placeholder div
- `{{STATUS_CLASS}}` – CSS class: `success` or `error`
- `{{TITLE}}` – Page title (e.g. "Login successful", "Login failed")
- `{{MESSAGE}}` – Main text (escaped for HTML)
- `{{SUCCESS_EXTRA}}` – Extra HTML only on success (e.g. countdown); empty on error

You can change styles, layout, and copy. Keep the five placeholders so the launcher can fill them in.
